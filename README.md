# VisitPNG — Official Tourism Platform of Papua New Guinea

**VisitPNG — Land of a Million Journeys**

Enterprise tourism and travel companion platform for Papua New Guinea, providing verified destination catalogues, interactive vector GIS mapping across all 22 provinces, Kokoda Track GPS waypoint trails, cultural sing-sing festival passes, 24/7 Wantok AI travel concierge, and SafeTravel emergency guidance.

## Architecture
- **Framework**: Next.js (App Router), React, TypeScript
- **Database**: SQLite / Cloudflare D1 with Drizzle ORM
- **Mobile**: Android Trusted Web Activity (TWA) with Google Play Billing integration
- **Styling**: Vanilla CSS tokens with responsive mobile-first layouts
- **Brand Typography**: Ubuntu Google Fonts
